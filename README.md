# Disable Island Feature (Magisk Module)

A simple Magisk module to completely disable the system dynamic island/pill animation on Android devices. This is highly recommended for **PortRoms** where the island feature is misaligned or off-center due to hardware camera cutout differences.

## Features
- Disables `persist.sys.feature.island`
- Disables `feature.island.debug`
- Cleans up and aligns the status bar properly for notifications.

## Installation
1. Download the `DisableIsland.zip` from this repository.
2. Open the **Magisk App**.
3. Go to the **Modules** tab.
4. Click **Install from storage** and select the downloaded ZIP file.
5. **Reboot** your device.
